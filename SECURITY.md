# Security policy

## Supported version

Security fixes are made against the latest published release.

## Reporting a vulnerability

Please do not publish suspected vulnerabilities or printer credentials in a normal issue. Use GitHub's **Report a vulnerability** option in the Security tab to open a private report.

Include the affected Spooly version, operating system, a concise reproduction, expected impact, and any relevant source locations. Redact access codes, serial numbers, private addresses, and configuration files.

Printer compatibility problems without a security impact belong in the public issue tracker.
